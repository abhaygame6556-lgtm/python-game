# 🐍 Snake Game (Pygame)

A classic **Snake Game** built with **Python** and **Pygame**.  
Control the snake, eat the food, and try to get the highest score without colliding with yourself or the walls!

---

## 🎮 Features

- Smooth snake movement using Pygame.
- Score tracking system.
- Pause and restart functionality.
- Game Over screen with score display.
- Simple and clean UI.
